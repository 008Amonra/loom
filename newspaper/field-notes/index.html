2026-07-23infrastructure / n8n

n8n update was smoother than expected

Updated n8n from 2.8.4 to 2.31.5. Had to upgrade Node.js first (22.14 to 22.22), then create a wrapper script because the systemd service pointed to the old path. The wrapper bridges new Node to old n8n. Hacky but it works. Version numbers in software are just vibes anyway.
