Tools Hub

8 free browser tools - PDF merge/compress, image compress, QR code, JSON formatter, color palette, video→GIF, text diff.

Visit source

Why it matters: No signup, no ads, no tracking. Tools that work and get out of the way.

A collection of 8 small tools that run entirely in the browser. No server uploads for most operations. No accounts. No cookies.

The Tools

  • PDF Merge - combine multiple PDFs into one. Drag, drop, done.
  • PDF Compress - shrink PDF file size via Ghostscript. Good for email attachments.
  • Image Compress - reduce JPEG/PNG size without visible quality loss.
  • QR Code Generator - text, URL, or contact info to QR code. Download as PNG.
  • JSON Formatter - paste ugly JSON, get indented, colored, readable JSON.
  • Color Palette - pick colors, export hex/rgb/hsl. Good for quick design work.
  • Video → GIF - convert short video clips to animated GIFs.
  • Text Diff - compare two text blocks side by side. Highlight differences.

Field Note

The QR code tool is the most underrated. Clients always need QR codes for posters, business cards, and flyers. This one generates them instantly with no watermark.
