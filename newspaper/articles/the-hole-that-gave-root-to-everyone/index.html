The Hole That Gave Root to Everyone

A Linux kernel flaw called Bad Epoll lets any unprivileged user gain full root access. It affects desktops, servers, and Android. An AI model found it.

A newly disclosed Linux kernel vulnerability called Bad Epoll (CVE-2026-46242) allows any unprivileged user on a Linux system to gain full root access. It affects Linux desktops, servers, and Android devices. A patch is available.

The vulnerability sits in the same stretch of kernel code where Anthropic’s most powerful AI model, Mythos, recently discovered a different flaw. This is the first time an AI model has found a critical kernel vulnerability before human researchers.

What Bad Epoll Does

Linux uses a mechanism called epoll to efficiently monitor multiple file descriptors - think of it as the kernel’s way of managing who gets to talk to which services. It is one of the most fundamental building blocks of Linux networking and I/O.

The flaw is a race condition in the epoll subsystem. Race conditions occur when two operations happen simultaneously in a way the programmer didn’t anticipate. In this case, an attacker can trigger a specific sequence of epoll operations that corrupts kernel memory in a predictable way.

The result: an ordinary user with no special permissions, no exploits, and no credentials can escalate to root - full control of the machine.

Who Is Affected

The vulnerability affects:

  • Linux desktops - every major distribution
  • Linux servers - cloud, on-premise, container hosts
  • Android devices - the Linux kernel underpins Android
  • Multi-user environments - any system where untrusted users have login access

This is not a niche bug. epoll is used everywhere. Any system running a Linux kernel between versions 5.x and 6.x is potentially vulnerable.

How It Was Found

The vulnerability was discovered through a collaboration between human researchers and Anthropic’s Mythos model - a large language model trained specifically for code analysis and vulnerability research.

Mythos identified the flaw in the same epoll code path where it had previously found a different vulnerability. The researcher who reported it noted that the model found the pattern by analyzing kernel code at a level of detail and speed that would have taken human researchers weeks.

This is the most significant example yet of AI-driven vulnerability discovery. Not a tool that scans for known patterns, but a model that reasons about code logic and finds novel flaws.

The Race Condition Explained

For those who want the technical detail:

The epoll subsystem maintains internal state across multiple system calls. When two threads execute epoll operations concurrently, there is a window where the kernel’s internal bookkeeping can be corrupted. By carefully timing these operations, an attacker can overwrite a kernel function pointer with a controlled value.

The attacker then triggers the corrupted function pointer, redirecting kernel execution to attacker-controlled code. Since this runs in kernel mode, the attacker gets root.

It is elegant, terrifying, and remarkably simple once you know where to look.

What to Do

Patch immediately. Distributions are releasing updates:

# Debian/Ubuntu
sudo apt update && sudo apt upgrade

# Fedora/RHEL
sudo dnf update kernel

# Arch
sudo pacman -Syu

If you cannot patch immediately, consider:

  • Disabling unprivileged user namespaces (if not needed)
  • Running epoll-heavy services in containers with restricted capabilities
  • Monitoring for unusual privilege escalation attempts

The AI Angle

The fact that an AI model found this vulnerability is significant for two reasons:

  1. Speed - Mythos analyzed kernel code and identified the flaw in hours, not weeks
  2. Novelty - this was not a known pattern match but a reasoning-based discovery

The security community is divided on what this means. Some see it as a defense breakthrough - AI finding flaws before attackers do. Others see an arms race escalation - if AI can find kernel vulnerabilities, so can AI-powered attackers.

The truth is probably both.

The Pattern

Bad Epoll is the third critical Linux kernel vulnerability disclosed in July 2026. The month has also seen:

  • SimpleHelp CVE-2026-48558 - CVSS 10.0, authentication bypass
  • Adobe ColdFusion - six critical flaws, CVSS 10.0, actively exploited
  • Microsoft Defender zero-days - privilege escalation

July 2026 is shaping up as one of the most intense months for critical vulnerabilities in recent memory. The patch window is shrinking. Attackers are moving faster. And now, AI is both the shield and the sword.

The hole was there the whole time. A machine found it. Patch your systems, or someone else’s machine will find it too.
