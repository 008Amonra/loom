n8n 2.35: Self-Hosting AI Is Now a One-Line Command

Self-hosting n8n used to mean a Docker Compose file, a pile of environment variables, and a sandbox you wired up yourself. The kind of project that looks exciting on a Saturday and quietly makes you regret having a Saturday.

With n8n 2.35, that’s a shell command:

curl -fsSL https://get.n8n.io | sh

The installer drops in n8n via Docker Compose and pre-configures the two fiddly bits that used to be manual work: the code sandbox and the private web search the AI assistant uses. Both run on your own machine. n8n itself is the free Community edition, so the only thing you pay for is the model provider you plug in.

The AI Assistant Goes Local

The headline feature is that the AI assistant — the natural-language workflow builder Cloud users have had since July — now works on self-hosted instances. Describe a workflow in plain words; it gets built, tested, and corrected. Bring an Anthropic, OpenAI, or OpenRouter key, or point it at a local model.

Which is the quiet part, and it’s the right one. For anything with sensitive data — client files, medical records, company financials — the realistic architecture is not “send everything to a provider”, it’s “keep the workflows and the data at home, and decide deliberately what crosses the line.” n8n’s community edition being the free core of that stack is why it keeps showing up in privacy-first setups. It’s also the stack behind the self-hosted agents and n8n workflows we run and operate for clients — automation on your own hardware, no data leaving the building.

What the One-Liner Actually Deploys

The installer pulls the same well-worn kit that powers most self-hosted AI labs:

  • n8n — low-code workflows with 400+ integrations and AI components
  • Ollama — local LLMs, so inference can stay on-device too
  • Qdrant — vector store for memory and RAG
  • PostgreSQL — the workhorse underneath it all

For local setups there’s one wrinkle worth knowing: containers reach the host’s Ollama through host.docker.internal:11434, so after install you head to the credentials page and point the Local Ollama service at that base URL. It’s a two-minute fix, documented in the starter kit, and the kind of detail that used to cost people an afternoon.

What People Build

The starter kit’s example workflows sketch the mainstream: scheduling-appointment agents, PDF summarization without data leaks, smarter Slack bots, private financial-document analysis. One is worth calling out because it’s quietly the most common ask right now — the AI agent that scrapes pages, thinks, and answers, which is precisely the load that’s getting cheaper to run locally every quarter as 30B-class models fit on consumer GPUs.

The n8n Labs angle is worth a skeptical look too: hosted, isolated AI agents with persistent memory are now sold as a service on top of n8n — “bring your own key” from €50/month. It’s a sign of the market maturing, and a reminder that the same thing runs free if you own the hardware.

The Signal

Read it as a chemistry test for the self-hosting thesis. The parts were always available; what’s new is that assembly is now trivial, and that the AI assistant — the piece that makes automation approachable — no longer requires the cloud plan. When the friction disappears, the interesting question shifts from “can I” to “should I”, and for a growing share of workloads the answer is: at home, thanks.
