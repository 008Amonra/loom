Everything Is a Plugin

DeepSeek releases Harness, an open-source agent framework where models, tools, sandboxes, and even the agent loop itself are swappable configuration. China's national supercomputing platform picked it up within 48 hours.

Most AI agent frameworks are monoliths with configuration files. DeepSeek’s new Harness is a collection of plugins with a meta-framework.

The difference matters more than it sounds.

The Architecture

Harness is built on Cordis, a meta-framework developed by researchers at Peking University and DeepSeek-AI. The core idea: every component — the model, the tools, the execution environment, the agent loop itself — is a replaceable plugin. At startup, multiple configuration “bundles” are layered to assemble a named profile.

This means you can switch from running a coding agent on your local filesystem to running it in a remote sandbox without rewriting a single line of the framework. Change the config, change the behavior.

The framework ships with four execution modes:

  • Standard: a full coding agent with file operations, shell access, and search
  • Code: bundles multiple tool calls from model-generated code
  • Eval: for evaluating models in an isolated environment
  • Creator: inspects the running configuration and tests plugins in memory

Developers can launch the web UI with npx@deepseek-ai/dshweb. The full source is on GitHub under the MIT license.

The National Play

On August 15, one day after the developer preview went live, China’s National Supercomputing Internet announced that both DeepSeek-v4-Pro-0813 and DeepSeek Harness were available on its platform. The system serves what is described as China’s first 100,000-accelerator resource pool integrating supercomputing and AI computing.

The speed of adoption tells a story. A developer preview, picked up by national infrastructure within 48 hours, suggests the framework was already in the pipeline — or that the political will to back domestic AI tooling is strong enough to move faster than open-source communities usually do.

Wang Peng, associate research fellow at the Beijing Academy of Social Sciences, told the Global Times that the rollout “links advanced models and agent frameworks to the national computing infrastructure.”

Why It Matters

The AI agent space is fragmenting. Every lab — Anthropic, OpenAI, Google, Meta — is building its own agent framework, its own tool protocol, its own sandbox. The result is a Tower of Babel where agents built on one framework cannot talk to agents built on another.

Harness does not solve this problem. But it does something useful: it makes the agent’s own internals modular. If a better model comes out, swap it in. If a better sandbox exists, point the config at it. If the agent loop itself needs to change, replace the plugin without touching the rest of the system.

Armin Ronacher, who led the development of PI Agent, commented on Hacker News that although Harness is “not perfect, there is a freshness to it that makes you want to reconsider design choices in this area.”

That freshness may be exactly what the agent ecosystem needs: not another framework that claims to do everything, but a framework that gets out of the way and lets you swap the parts that are broken.

The developer preview is available now. Official API and configuration compatibility changes are forthcoming.
