The Password You Never Remember

Password managers solve a problem that never should have been yours.

Every year, the same list appears: “Most Common Passwords.” Every year, the top entries are 123456, password, and qwerty. Every year, people are surprised.

The surprise is not that people use bad passwords. The surprise is that anyone still remembers passwords at all.

The Memory Problem

A human brain can hold about seven items in short-term memory. A modern password policy requires: 16+ characters, uppercase, lowercase, numbers, symbols, no repeats, no dictionary words, no personal information, changed every 90 days.

These requirements are incompatible with human memory. They are compatible with a file. A file you lock with one strong password and never think about again.

This is what a password manager does. It remembers every password so you do not have to. You remember one master password. The manager handles the rest.

What a Password Manager Actually Stores

A password manager is an encrypted database. The encryption is usually AES-256 or XChaCha20 - algorithms that have been public for decades and have never been broken. The master password is the key. Without it, the database is random noise.

The manager stores:

  • Passwords - random strings like k9#mP2$vL8@nQ4xR
  • Usernames - your email, login names
  • TOTP codes - two-factor authentication tokens
  • Secure notes - recovery codes, API keys, recovery phrases
  • Passkeys - FIDO2/WebAuthn credentials (the newer standard)

When you visit a site, the manager fills the fields automatically. You never see the password. You never type it. You never reuse it.

Why Reuse Is the Real Problem

The average person has 168 online accounts. If you use the same password for five of them, and one site gets breached - and sites get breached regularly - every account using that password is now vulnerable.

This is called credential stuffing. It is automated. Botnets try leaked email/password combinations against thousands of sites per minute. The attack works because people reuse passwords.

A password manager eliminates reuse by generating a unique random password for every account. You never see them, so you never reuse them.

The Master Password

The single point of failure is the master password. It must be:

  • Long - 20+ characters, ideally a passphrase (four or five random words)
  • Unique - never used anywhere else
  • Remembered - because you cannot store it in the manager itself

A passphrase like correct-horse-battery-staple is both memorable and strong. The entropy of four random words from a 7776-word dictionary is about 51 bits - strong enough for most threat models.

Which Manager

The Redaktor does not endorse products. But the landscape is simple:

  • KeePassXC - local database, no cloud, open source. You control the file. Best for people who do not want their passwords on someone else’s server.
  • Bitwarden - cloud-synced, open source, free tier available. Best for people who want passwords on all devices without effort.
  • 1Password - cloud-synced, closed source, subscription model. Polished, but you trust a company.

All three are better than not using one. The worst password manager is better than the best human memory.

The Transition

Moving to a password manager takes an afternoon. The steps are:

  1. Install the manager
  2. Create a strong master password (passphrase)
  3. Let it capture your existing logins as you visit sites
  4. Over time, change reused passwords to random ones
  5. Enable two-factor authentication where available

The first login takes effort. After that, you never type a password again. The browser extension or phone app handles it.

What You Gain

  • No reuse - every account has a unique password
  • No memory burden - one passphrase, not 168 passwords
  • Breach detection - many managers alert you when a site is breached
  • Phishing resistance - the manager fills credentials only on the correct domain
  • Shared access - family plans let you share passwords securely

What You Risk

  • Single point of failure - if your master password is weak or compromised, everything is exposed
  • Cloud trust - cloud-synced managers require trusting the provider’s encryption and infrastructure
  • Availability - if the manager’s servers are down, you cannot log in to new sites (cached logins still work)

The risk is real but manageable. A strong master password and two-factor authentication on the manager itself reduce it to acceptable levels.

The Bottom Line

Password managers are not a convenience feature. They are a security tool that also happens to be convenient. The question is not whether you should use one. The question is why you are still typing passwords.
