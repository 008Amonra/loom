The Swiss German Weather Briefing

Open-Meteo has 63 languages. Swiss German is not one of them. A small machine fixes that.

Open-Meteo supports 63 languages. Swiss German is not one of them.

That is a strange gap for a weather API that originates in Switzerland. The data is accurate. The documentation is thorough. The API is free for non-commercial use. But if you want your morning forecast delivered in the dialect spoken within walking distance of the API’s own servers, you need a small machine of your own.

What The Machine Does

The Swiss German Weather Briefing is a shell script that runs at 07:30 every day. It does three things:

  1. Fetches today’s weather from Open-Meteo for a fixed location
  2. Translates the result into phonetic Swiss German
  3. Sends it to Telegram

The translation is not perfect. It is a phonetic approximation: German words rewritten to sound like Zürich dialect. “Regen” becomes “Räge.” “Bewölkt” becomes “bewölkt” (which happens to be the same). “Windgeschwindigkeit” becomes “Windigschwindigkeit” because that is closer to how it actually sounds when someone says it fast over breakfast.

The point is not precision. The point is that a weather forecast in your own dialect feels different from one in standardized German. It feels local. It feels like it was meant for you.

How It Works

The script calls the Open-Meteo API with a latitude, longitude, and timezone. It requests daily variables: temperature, weather code, wind speed, precipitation probability, and UV index.

The API returns JSON. The script parses it with jq. Then a substitution table maps each weather code to a Swiss German description:

  • Clear sky → “Klarer Himmel”
  • Partly cloudy → “Teils bewölkt”
  • Rain → “Räge”
  • Thunderstorm → “Gewüter”
  • Snow → “Schnee”

Temperature, wind, precipitation probability, and UV index are inserted as numbers. The result is a single paragraph: the day’s weather in a language that sounds like home.

The output is piped to the Telegram MCP bot, which sends it to a fixed chat. The whole thing runs in under two seconds.

Why It Matters

A weather forecast is one of the most frequently consulted pieces of public data. Most people check it in a language that is technically correct but emotionally flat. A forecast in your dialect does the same job but lands differently.

This is a small thing. But small things that run reliably every day accumulate into a different relationship with information. The machine does not just deliver data. It delivers data in a voice.

The Swiss German Weather Briefing also demonstrates something about Open-Meteo that is easy to miss: the API is good enough that a ten-line script can turn it into something personal. No API key. No rate limit anxiety. No dashboard. Just a URL, a location, and a response.

Limitations

The phonetic translation is manual. It covers maybe forty weather conditions. If Open-Meteo adds new codes, the script will miss them until someone updates the table. The location is hardcoded. Moving it requires editing the script. The Telegram chat ID is also hardcoded. This is a single-user machine.

None of these are serious problems for what the machine is. A weather briefing for one person in one dialect from one location does not need to be a platform.

Verdict

  • Practicality: high
  • Cost: zero
  • Daily value: high

The Swiss German Weather Briefing is a small machine that makes public data feel local. It costs nothing to run, takes two seconds to execute, and leaves a useful residue: the habit of expecting your tools to speak your language.

That is enough.
