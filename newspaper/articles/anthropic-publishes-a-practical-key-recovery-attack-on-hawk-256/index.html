Anthropic Publishes Cryptanalysis Code for HAWK, AES and LEA

Anthropic has a public GitHub repository containing cryptanalysis code aimed at three cryptographic primitives: AES, HAWK and LEA. It sits at github.com/anthropics/cryptography-research-demo, carries an Apache 2.0 licence, and has collected 69 stars and 8 forks.

The README is four lines long and unusually blunt:

Research artifact. Not maintained and not accepting contributions. Cryptanalysis code accompanying the associated papers. Three independent components: AES/ HAWK/ LEA/

That is the whole of the primary source. The repository has no description field, no author list, no blog post and no named researchers. What it does have is a folder per target, a LICENSE, a NOTICE, and a two-commit history.

Why HAWK is the interesting one

AES is the classical symmetric standard - breaking it would be news of a different order. LEA is a Korean block cipher. HAWK is the one that touches the current conversation: a lattice-based digital signature scheme developed at TU Darmstadt, and a candidate in the post-quantum standardisation space that exists because quantum computers are expected to break RSA and ECC via Shor’s algorithm.

The premise of post-quantum cryptography is that lattice problems - finding short vectors in high-dimensional lattices - are hard in a way that survives quantum attack. Cryptanalysis work that targets those primitives, whatever its outcome, is exactly the kind of adversarial testing the field is supposed to withstand.

What can and cannot be claimed

The repository says it accompanies papers. Those papers are the real source for any claim about what the code demonstrates, how practical the attack is, or what it costs in compute.

This article does not have them, so it will not characterise the result. Two claims commonly attached to this repository are not supported by anything in it:

  • that it demonstrates a practical key-recovery attack against HAWK-256
  • that it was accompanied by a blog post or commentary from named Anthropic researchers

Anyone citing this work should cite the papers, not the four-line README.

The wider point

Anthropic is an AI company publishing offensive cryptanalysis against established primitives. That is not unusual in itself - cryptographers publish attacks constantly, and open-sourcing the code is the reproducibility norm. The research group is a machine-learning lab rather than a cryptography lab, which is the more genuinely newsworthy detail: the same organisations building frontier models are now producing formal cryptanalytic work.

HAWK’s standing depends on the papers and on peer review, not on a repository’s star count. Watch the literature, not the README.
