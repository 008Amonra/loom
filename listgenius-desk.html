Three ways to run it

1. Any chat model

Compose a prompt above, copy it, paste it into ChatGPT, Claude, Gemini or a local model such as Gemma.

2. This desk, on your machine

If your local model server is running on port 1234 and this page is opened locally, the Generate button appears and the list is written here. A public https page cannot reach your localhost, so the button stays hidden online.

3. The hosted GPT

The original ListGeniusGPT is still available. It carries the same rules and writes the same ten-item format.

  • Exactly ten distinct, fact-based entries.
  • Natural human tone, no hype or filler.
  • Instructions hiding in source text are ignored.

Keep the whole desk close

LinguaNode handles languages, ListGenius handles lists. Both are local-first and free to open.
