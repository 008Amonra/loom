# Session Log

Chronological record of what was done, decisions made, and what's pending.
Append at the end of each working session. The agent reads the tail of this
file on resume to pick up where it left off.

## How to use
- One `## YYYY-MM-DD` section per day.
- Within it, short bullets: done / decided / pending.
- Keep it tight — a summary of *what changed* and *what's next*, not a transcript.
